Plain Craft Launcher (PCL) PCLR 是第三方独立修改版，基于龙腾猫跃的 [PCL 2.99.0.0](https://github.com/Meloong-Git/PCL/commit/6b9a50df911c9d68b69b24c979efba477fb14b67)。[支持原作者](https://meloong.com/afd/a/LTCat)

本版恢复 Minecraft 下载、自动安装及整合包安装入口，使用 PCLR 标识，并将更新入口指向本仓库。保留上游许可、原作者署名、蓝色界面、正版购买与赞助劝导。

普通用户请选择 **windows-Release.zip**，解压后运行 **PCLR.exe**；独立 `.exe` 也可直接使用。Debug、Snapshot 构建供排错及预览使用。需要 64 位 Windows 与 .NET Framework 4.8。

微软登录与 CurseForge 需要使用者自行提供对应应用配置；本发行不包含上游私有配置。Minecraft 下载仍使用原有官方源及镜像源。

附带三种构建的便携包、独立程序、包含 MeloongCore 的完整源码包及 SHA-256 校验清单。历史发行中的“上游归档”是上游原版，不包含本版修改。
